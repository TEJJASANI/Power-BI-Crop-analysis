#  Crop Analysis Dashboard (Power BI)

##  Overview

This project presents an interactive **Crop Analysis Dashboard** built using Power BI, focused on analyzing crop suitability, production categories, and environmental factors such as rainfall, pH level, and region.

The dashboard helps identify optimal crop conditions and patterns for better agricultural decision-making.

---

##  Objectives

* Identify best crops based on environmental suitability
* Analyze crop distribution across regions
* Understand impact of rainfall and pH on crop growth
* Compare crop categories (Fruits vs Pulses)
* Evaluate crop generation levels (High, Medium)

---

##  Key Features

*  Region-wise analysis (Central, North, West/Central)
*  Rainfall insights (Average rainfall visualization)
*  Crop suitability indicators (Rainfall, Temperature, pH)
*  Season filter (Summer, Monsoon, Winter)
*  KPI cards (Best Season, Region, pH Category, Crop Type)
*  Category comparison (Fruits vs Pulses)

---

##  Dataset Description

The dataset includes agricultural attributes such as:

* Crop Label
* Crop Category (Fruits, Pulses)
* Region
* Season
* Rainfall
* pH Category (Acidic, Neutral, Alkaline)
* Crop Generation Category (High, Medium)
* Suitability indicators (Rainfall, Temperature, Region)

---

##  Key Insights

* **Pulses dominate production (~60%)** compared to fruits
* **Neutral pH soil is most suitable** for majority of crops
* **Summer is the most favorable season** for crop growth
* **Central region shows highest crop concentration**
* High crop generation category is more frequent than medium
* Crop suitability depends on combined factors (rainfall, pH, region)

---

##  Data Modeling

* Structured dataset with categorical and numerical features
* Relationships built for filtering across crop attributes
* DAX used for KPI calculations and aggregations

---

##  How to Use

1. Open the `.pbix` file in Power BI Desktop
2. Use slicers (Season, Region, Crop Type)
3. Analyze KPIs and visual charts for insights
